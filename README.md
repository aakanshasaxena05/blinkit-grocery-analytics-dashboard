# 🛒 Blinkit Grocery Analytics Dashboard (Power BI)

An end-to-end Business Intelligence project built using **Microsoft Power BI** to analyze Blinkit grocery sales, customer behavior, and outlet performance. The dashboard provides interactive visualizations and actionable insights to support data-driven business decisions.

---

## 📂 Project Structure

- **BlinkIT Grocery Data.xlsx** – Raw dataset containing sales transactions, item details, customer ratings, and outlet information.
- **BLINKIT DASHBOARD.pbix** – Power BI dashboard with interactive reports, data modeling, and DAX calculations.
- **README.md** – Project documentation.

---

## 🚀 Dashboard Features

- 📈 Total Sales Analysis
- 💰 Average Sales per Transaction
- 📦 Total Items Sold
- ⭐ Customer Rating Analysis
- 🏪 Outlet Performance by Location & Size
- 🛍️ Item Type Analysis
- 📅 Outlet Establishment Year Analysis
- 🎛️ Interactive Filters and Slicers
- 📊 Business Performance Dashboard

---

## 📊 Key Performance Indicators (KPIs)

- **Total Sales**
- **Average Sales**
- **Total Items Sold**
- **Average Customer Rating**
- **Number of Outlets**
- **Sales by Outlet Tier**
- **Sales by Item Type**
- **Sales by Outlet Size**

## ⚙️ How to View the Dashboard

1. Clone the repository:


2. Open **BLINKIT DASHBOARD.pbix** using **Microsoft Power BI Desktop**.

3. Explore the dashboard using the available slicers, filters, and visualizations.
